# Box profiles

This fork tracks exactly three TV boxes. The profiles name each box without storing its IP address, serial number, Wi-Fi name or account details.

| Box | Profile | Theme recorded in this fork |
|---|---|---|
| Friend's T9 box | [`t9.md`](t9.md) | No device theme recorded yet |
| Birżebbuġa box | [`birzebbuga.md`](birzebbuga.md) | No device theme recorded yet |
| Luqa box | [`luqa.md`](luqa.md) | [`family-gozo`](../themes/family-gozo/) |

`main` contains the shared launcher and the three profiles above. Branches are temporary development work rather than device identities. Installing a GitHub update on a box remains a separate, user-approved action.
