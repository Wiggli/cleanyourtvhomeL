# Luqa box

This is the user's parents' box in Luqa. It is one of the three tracked boxes and currently uses the [`family-gozo`](../themes/family-gozo/) theme.

The theme name describes the Gozo photographs shown on the box; it does not describe the box's location. Updates to the repository do not install themselves on this box.

## Active work

Draft PR [#1](https://github.com/Wiggli/cleanyourtvhomeL/pull/1) contains the football add-on intended for this box. Its initial interests are Manchester United, AC Milan, England and Italy, with team and competition choices available through the television settings screen. It remains unmerged until it can be installed and verified on the Luqa box, so its branch must be retained.
